# Q：更新index.html后发现GitHub Pages没有变化？
A：当你访问一个网站时，浏览器为了让你加载更快，会把 CSS 和 JS 文件缓存到本地。当你重新上传新文件时，浏览器一看文件名还是叫 style.css，它就觉得：“嗯，文件没变，直接用我本地存的旧版本吧。”
解决方法：强制刷新缓存（立刻见效）
在你的博客网页上，同时按下键盘上的 Ctrl + Shift + R（如果是苹果 Mac 电脑，按 Command + Shift + R）。
这行操作会强制浏览器忽略本地缓存，去 GitHub 服务器上下载最新的文件。99% 的情况下，按下这个快捷键后，新样式就会立刻出现了。
